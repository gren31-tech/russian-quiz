# 📖 Русский язык: Тесты для детей

Мобильное приложение для Android с тестами по русскому языку для школьников.

## 📱 Возможности приложения

- **5 тестов** по разным темам:
  - 🔤 Алфавит и буквы (10 вопросов)
  - 🎵 Гласные и согласные (10 вопросов)
  - ✏️ Правила написания (жи-ши, ча-ща и др.) (10 вопросов)
  - 📝 Части речи (10 вопросов)
  - 💬 Предложения (10 вопросов)

- **Система баллов**: 10 очков за каждый правильный ответ
- **Таймер**: 20 секунд на каждый вопрос
- **Подсветка**: зелёный = правильный ответ, красный = ошибка
- **Сохранение результатов** между сессиями
- **Работает полностью офлайн**

## 🔨 Как получить APK

### Способ 1: GitHub Actions (автоматически)

1. Создайте аккаунт на [github.com](https://github.com) (если нет)
2. Создайте новый репозиторий
3. Загрузите все файлы из этой папки в репозиторий
4. Перейдите в **Actions** → **Build Android APK** → **Run workflow**
5. После завершения скачайте APK из раздела **Artifacts**

### Способ 2: Загрузить через Git

```bash
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/ВАШ_НИК/russian-quiz.git
git push -u origin main
```

## 📲 Установка APK на телефон

1. Скачайте APK файл на телефон
2. Зайдите в **Настройки → Безопасность → Разрешить установку из неизвестных источников**
3. Откройте файл APK и нажмите **Установить**

## 🎯 Минимальные требования

- Android 5.0 (Lollipop) и выше
- ~5 МБ свободного места
